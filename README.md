# SemEval-2026 Task 4: Narrative Story Similarity and Narrative Representation Learning
## Task Description
The participants are asked to identify narratively similar stories. The narrative similarity is defined by three core similarity components: the abstract theme, the course of action, and the outcomes of a story.\
We primarily focus on tackling **Track A**, where the system gets a triple consisting of an anchor story and two choices: A and B. The system is asked to identify which of the two choices is more similar.\
More information can be found on the [Website of Task4](https://narrative-similarity-task.github.io/)
